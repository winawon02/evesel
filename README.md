# EVESEL | 반응형 메인 홈페이지

Penpot **01 / HOME / Desktop 1920**, **01 / HOME / Mobile 390** 시안을 기반으로 한 이브셀 메인페이지입니다.

## 구성

- 순수 HTML / CSS / JavaScript (프레임워크, 빌드 도구 없음)
- PC 1920px 및 모바일 390px 디자인 기준 반응형 (중간 너비 대응)
- 히어로, 브랜드/제품 자동 롤링, 4개 제품 카테고리, OEM/ODM, 제조 역량, R&D, 문의, 푸터
- Penpot 원본 이미지 리소스 `assets/` 포함
- 스크롤 반응형 헤더, 전체 메뉴, KR/EN 텍스트 전환, 자동 롤링, 모션 감소 접근성 대응
- Pretendard 웹폰트는 공식 배포 CDN을 통해 불러옵니다. 폰트 요청에 실패하면 OS 기본 한글 글꼴로 표시됩니다.

## 실행

`index.html` 파일을 브라우저로 열거나 아래 명령어로 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000`으로 접속합니다.

## 파일 구조

```text
index.html
css/style.css
js/main.js
assets/        # Penpot에서 추출한 원본 이미지 25개
README.md
```

현재 작업 범위는 **메인페이지 1개**입니다. 내비게이션은 메인페이지의 해당 섹션으로 이동하며 별도 서브페이지는 아직 구현하지 않았습니다. 문의 버튼은 담당 이메일로 연결됩니다.

## 폰트 자체 호스팅 옵션

현재 스타일시트는 Pretendard 공식 CDN을 사용합니다. 제공받은 OTF를 자체 호스팅하려면 `fonts/` 디렉터리로 저장한 뒤 `css/style.css`의 상단 폰트 import를 로컬 `@font-face` 선언으로 변경하면 됩니다.

## 2026-11-11 영상·제품 컬러 갤러리 업데이트

- 메인 히어로: 15초 MP4 자동 재생(무음, 반복) + 전용 WebP 포스터 + 정지 이미지 폴백.
- 38종 실제 제품 누끼: 패키지 컬러 기준 **핑크·민트·크림·화이트·블루·골드·블랙 7개 그룹**. 38종의 번호와 배치는 `assets/media-manifest.json`에서 확인.
- 모바일 터치 스와이프/PC 화살표·키보드 탐색·자동 전환(사용 중 자동 일시중지).
- 스크롤 섹션 순차 등장, 클리핑 리빌, 이미지 패럴랙스, 상단 진행 표시, 히어로 텍스트 모션.
- 사용자의 모션 감소 설정 및 데이터 절약 설정을 존중합니다.

### 설치 및 현재 상태

**메인 브랜치에 미디어 업로드 완료** — 이전 안내의 별도 ZIP 업로드는 더 이상 필요하지 않습니다.

- `assets/hero-loop.mp4`: 원본 영상을 1920×1080, 15초 H.264로 웹 최적화한 배경 영상 (6.66 MB)
- `assets/hero-poster.webp`: 영상 프레임을 추출한 초기 로딩 포스터 (약 50 KB)
- `assets/products/product-01.webp` ~ `product-38.webp`: 첨부 누끼 ZIP의 38종 실제 제품 이미지
- `assets/media-manifest.json`: 7개 색상 그룹별 제품 매핑 (38종 중복·누락 없음)

GitHub Actions의 일회성 분할 영상 업로드가 성공했고 임시 `.hero-parts` 파일은 정리됐습니다. 전체 사이트는 별도 빌드 과정 없이 `index.html`로 구동됩니다. 실제 배포는 사용하는 호스팅 환경의 자동배포 설정을 따릅니다.

### 반응형·모션 확인 사항

PC에서는 컬러별 제품 갤러리 좌우 화살표와 포인터 일시정지를, 모바일에서는 터치 스와이프와 자동 전환을 지원합니다. 스크롤 리빌, 이미지 패럴랙스, 진행 표시, 히어로 모션은 순수 CSS/JavaScript로 구현되며 `prefers-reduced-motion`을 지원합니다.
